# Webpack Template Repository
This repository serve as a template for webpack projects which prevent the process having to set up webpack repository,configuring and install dependencies manually.

## Webpack file
- webpack.common.js
- webpack.dev.js
- webpack.prod.js

## Dependencies
- css-loader
- html-loader
- html-webpack-plugin
- style-loader
- webpack
- webpack-cli
- webpack-dev-serve
- webpack-merge

## How To Get This Webpack Template Repository
```bash
  git clone git@github.com:osmanamin0448/webpack-template.git
```
## How to Install Dependencies
**NOTE** this should be called once and all dependencies listed in **package.son file** will be installed
 ``` bash
 npm install
 ```

## How to Run or Start project
```bash
npm run build
```

## How To Stop Project Running
Press **control** + **c** from the keyboard
